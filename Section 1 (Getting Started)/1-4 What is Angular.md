## Angular trong khóa học Ionic

## Yêu cầu tiên quyết

**Quan trọng:** Biết Angular là điều kiện tiên quyết (prerequisite) của khóa học này.

**Module ôn tập Angular:**

- Hoàn toàn tùy chọn
    
- Chỉ dành cho việc làm mới kiến thức
    
- Không dạy Angular từ đầu
    
- Dành cho người đã học Angular trước đó
    

**Nếu chưa biết Angular:** Cần học khóa học Angular đầy đủ trước khi bắt đầu khóa học này.

## Angular là gì?

Angular là framework giúp phát triển ứng dụng web điều khiển bằng JavaScript (JavaScript-driven web apps) dễ dàng và thú vị hơn.

**Lợi ích của Angular:**

- Không cần tập trung vào các chi tiết kỹ thuật nhỏ (nitty-gritty details)
    
- Angular xử lý việc render UI (giao diện người dùng)
    
- Tạo ứng dụng một trang (single page application)
    
- Cho phép tập trung vào business logic (logic nghiệp vụ)
    
- Xây dựng ứng dụng web reactive mạnh mẽ
    

**So với Vanilla JavaScript:**

- Có thể làm mọi thứ bằng vanilla JavaScript nhưng rất tốn công
    
- Phải "phát minh lại bánh xe" (reinvent the wheel)
    
- Dễ tạo ra lỗi (bugs)
    
- Angular làm theo best practices và giải phóng thời gian cho business logic
    

## Single Page Application (SPA)

**Đặc điểm:**

- Chạy trên một trang HTML duy nhất
    
- Trang hoặc một phần trang được render lại liên tục qua JavaScript
    
- Angular điều khiển quá trình render
    
- Người dùng thấy như trang hoàn toàn thay đổi
    
- Tạo ảo giác có nhiều trang khác nhau
    

**Ưu điểm:**

- Chuyển đổi tức thì giữa các trang
    
- JavaScript chạy trong trình duyệt
    
- Không cần chờ phản hồi từ server
    
- Đây là lý do xây dựng app với JavaScript và sử dụng nhiều logic JavaScript
    

## Vai trò của Angular trong Ionic App

Angular giúp giải quyết các vấn đề phức tạp:

**Quản lý state và data:**

- Quản lý trạng thái (state management) giữa các trang khác nhau
    
- Quản lý dữ liệu (data management) trong ứng dụng lớn
    
- Tránh phức tạp khi ứng dụng phát triển
    

**Routing và Navigation:**

- Chuyển đổi giữa các trang
    
- Truyền dữ liệu giữa các trang
    
- Xử lý điều hướng trong ứng dụng
    

## Các lựa chọn thay thế

Ionic cũng hoạt động với:

- Vanilla JavaScript (không framework)
    
- React
    
- Vue
    

**Nếu muốn dùng React hoặc Vue:**

- Vẫn nên học các phần Quick Start và các section đầu
    
- Hiểu cách Ionic hoạt động
    
- Áp dụng kiến thức cho framework khác
    
- Một số điểm khác biệt nhưng Ionic components sử dụng tương tự
    
- Cách sử dụng components giống nhau
